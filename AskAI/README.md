# AskAI - LaunchBar Action

A powerful LaunchBar 6 action that brings Claude AI assistance directly to your fingertips. Chat with Claude, process text, and enhance your workflow right from LaunchBar.

## Features

- Modified from https://github.com/Ptujec/LaunchBar/tree/master/Ask-ChatGPT
- Direct integration with Claude AI
- Customizable personas and presets for different use cases
- Integration with various text editors for seamless workflow
- Recent chats history for easy reference
- Support for processing URLs and clipboard content
- Markdown support in responses
